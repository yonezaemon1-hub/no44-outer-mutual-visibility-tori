# Outer Mutual Visibility on Discrete Tori

## A Parity Defect and a Computer-Assisted Classification

Ryutaro Yonezu — Independent Researcher  
No.44, unrefereed AI-assisted preprint, version 0.3.

**Published on Zenodo:** [record and files](https://zenodo.org/records/23805765)  
**DOI:** [10.5281/zenodo.23805765](https://doi.org/10.5281/zenodo.23805765)  
Zenodo publication date: 30 October 2026 (UTC; 31 October in Japan).

The manuscript gives a computer-assisted classification of the outer mutual-visibility number of C_m Cartesian-product C_n for all integers 3 <= m <= n: 2m, with a one-point defect on odd squares, apart from 24 listed small exceptions. Analytical constructions cover the large-parameter families; the remaining block contains 39 finite cases.

## Review scope

Eight scoped AI-review reports found no new mathematical gap. They are not human peer review or complete independent certification of every implementation line. The final finite-value review inherited 36 reported independent numerical values whose source code and raw logs were not supplied; three further values have direct certificates. Known definitions, the fiber bound, and the values 3x3=4 and 4x4=6 are credited.
